Financial Statement P&L Matrix

A Power BI custom visual by Aider · Support & documentation

Build board-ready profit & loss statements in Power BI: define report sections with their own column layouts, add formula rows (subtotals, margins, ratios) calculated in the visual, drill into account hierarchies, style every row type independently, and export the finished statement to Excel.

Getting started

  • Add your account hierarchy to Rows, period fields to Columns, and measures to Values.
  • Open the visual's Edit mode (⋯ menu on the visual) to design sections, formula rows, and styling.
  • Non-additive measures (distinct counts, averages) are handled honestly: the visual uses model-computed subtotals where possible and shows a dash rather than a wrong number. For explicit DAX measures, set the aggregation mode per measure in the Section Editor (measure → Aggregation).
