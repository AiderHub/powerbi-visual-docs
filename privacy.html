Power BI custom visual published by Aider (org. no. 922 633 452), Norway · Last updated 2026-08-14

The short version: this visual does not collect, store, or transmit any data. Everything it displays stays inside your Power BI environment.

What the visual does with your data

The visual renders data that Power BI supplies to it from your report's semantic model (the fields you place in its Rows, Columns, and Values buckets). This processing happens entirely inside the Power BI sandbox in your browser or Power BI Desktop session.

  • No data leaves the visual. It makes no network requests of any kind — no telemetry, no analytics, no external services. This is enforced by Microsoft's Power BI visual certification program, which audits the source code and forbids external access.
  • No storage. The visual does not use cookies, browser storage, or any other persistence mechanism. Its display configuration (sections, formulas, styling) is saved by Power BI itself inside your report file, governed by your organization's Power BI tenant policies.
  • Excel export (optional button) generates the workbook locally in your browser session and hands it to you as a download. It is created from the data already shown in the visual and is never uploaded anywhere.

Personal data

The visual has no accounts, no sign-in, and no knowledge of who is viewing it. If the data you connect to Power BI contains personal data, that data is processed by Power BI under your organization's agreements with Microsoft; the visual only renders what Power BI provides, within Power BI.

Data controller and contact

Aider is not a data controller or processor for any data displayed through this visual — your organization remains in full control of its Power BI data. Questions about this statement or the visual: powerbi@aider.no. Aider's general privacy statement is available at aider.no (footer → Personvernerklæring).

Changes

If a future version of the visual changes any of the above (it would also have to pass Microsoft's re-certification), this statement will be updated and the date above revised.
